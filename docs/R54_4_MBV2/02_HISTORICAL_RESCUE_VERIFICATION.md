## 已備妥的驗證工具（檔案到位後 1 分鐘內可完成）

`scripts/mbv2-rescue-verify.js`：離線、唯讀，不連伺服器、不寫資料庫，支援 `.json`／`.json.gz`、舊版與 V2 格式。

```bash
node scripts/mbv2-rescue-verify.js \
  --old pos_migration_store_001_20261007.json \
  --new pos_migration_store_001_20261109.json \
  --merged merged_rescue.json \
  --gap-start 2026-10-08 --gap-end 2026-11-08 --store store_001 \
  --out rescue_report.md
```

輸出內容：
1. 各檔 SHA-256、格式、來源店家、匯出時間。
2. 實際重新計算：訂單列數、不重複訂單編號、檔內重複編號、缺編號、無日期、最早／最晚日期、LINE 會員（不重複 line_user_id）、Analytics 事件（以與匯入相同的去重鍵）。
3. 舊＋新聯集：只在舊備份（可恢復）、只在新備份、兩邊都有、兩邊內容不一致（列出編號）、聯集應得筆數。
4. 合併檔核對：是否等於聯集、缺少哪些、**多出哪些（兩份來源都沒有＝不可接受的補造）**、檔內重複。
5. 缺口區間逐日訂單數，列出兩份備份都沒有資料的日期。
6. 其他可能救援來源清單。

工具已用合成資料驗證邏輯（舊 743、新 66 其中 65 筆重複且 1 筆內容不同、合併 744）：正確算出「只在舊 678、只在新 1、兩邊都有 65、衝突 1、聯集 744、合併檔一致、缺口 32 天」。
