# 補貨通知營運操作說明（R54.4／MBV2-HF1-C6）

> 適用：店家後台「LINE 商品管理 → 補貨登記」。所有發送都經 LINE Messaging API；畫面上的「LINE 已受理」只代表 LINE 已收下請求，**不代表顧客已收到或已讀**。系統不會自動退款、不保證訊息送達。

## A. 上線前準備（只需一次）

1. 「系統設定 → LINE」已設定 Channel Access Token 與 LINE 會員 LIFF ID（商品直達連結需要）。
2. 補貨登記分頁：勾選「在 LINE 點餐頁顯示補貨登記入口」、設定登記有效天數、選擇消費者訂閱方式，按「儲存設定」。
3. 勾選「啟用 LINE 補貨通知發送」（總開關）。畫面顯示「目前可用」才代表設定完整。

## B. 手動發送（原本的方式，維持不變）

1. 點商品的「查看」→ 下方「🔔 補貨通知（店家手動發送）」。
2. 選取餐方式與日期（只能選系統判定可訂購的日期）→「預覽名單」。預覽會列出合格人數與各種排除原因。
3. 確認無誤 →「確認發送」。批次會逐筆送出，畫面自動更新進度。
4. 暫停的批次（例如額度用完、服務重新啟動）：確認原因後按「續送未完成項目」；結果待確認者只會以原 retry key 在有效時間內重試，不會換新 key 重送。

## C. 恢復販售自動通知（C6 新增，預設關閉）

### 開啟前
- 先用手動方式完成一次真機驗收（顧客實際收到訊息、點連結能開到商品）。
- 商品明細勾選「🤖 此商品參與恢復販售自動通知」（預設不參與）。只勾需要的商品。

### 開啟
- 勾選「恢復販售時自動發送補貨通知」，確認視窗會列出規則：
  - 只在**店家明確恢復販售**（販售狀態改為可販售、取消今日完售、上架、開啟外帶／外送）或**手動增加可售額度**，使商品由不可訂購變為可訂購時觸發。
  - 供應日期＝各取餐方式的最近可訂購日（伺服器依台北時間、最後接單時間、行事曆、休息日、預訂範圍、額度計算）；未來日期會以「已開放預購」通知。
  - 只通知已同意、同意屬於目前登記週期、未撤回、未取消、仍為好友、取餐偏好相符的登記；「都可以」只通知一次（外帶優先）。
  - 開啟時只建立觀測基線，目前已可售的商品不會追發。
- 不會觸發的情況：改名稱／價格／說明、重複儲存相同狀態、每日排程自動恢復、份數每日重設、訂單取消回補、備份還原、搬家匯入。

### 查看結果
- 「自動通知紀錄」：每次觸發的時間、商品、日期與取餐方式、狀態，以及每個方式的排入／排除人數與原因（例如「本週期已通知」「沒有合格且同意的登記」「總開關關閉」「供應日期已不可訂購」）。
- 商品明細的通知批次會標示「自動」；成效在「營運分析中心 → 補貨通知成效」，可依手動／自動篩選，口徑相同。

### 停用自動通知
1. 取消勾選「恢復販售時自動發送補貨通知」。
2. 系統會：取消尚未處理的觸發事件；執行中的自動批次在下一筆送出前暫停（原因「自動通知已關閉」）；已送出的請求照常保存結果。
3. 重新開啟時會建立新的觀測基線，不會追發停用期間的事件，也不會自動續送已暫停的批次。

### 處理未送出的自動批次
- 想送完：在該批次按「續送未完成項目」＝店家明確接手（標示「已人工接手」），沿用原逐筆紀錄與 retry key，之後不受自動開關影響。
- 不想送：按「取消未送出項目」。從未交給 LINE 的項目會取消並釋放週期名額；曾送出（含結果待確認）者保留紀錄、不會補送。
- 服務重新啟動後：自動批次中「從未交給 LINE」的項目會自動續送；送出後中斷而結果不明者維持「結果待確認」，由店家決定是否續送（只在 23 小時有效時間內、原 retry key）。

## D. 需求資料匯出

- 補貨登記分頁「匯出需求資料」：選狀態與登記日期（台北）→「⬇️ 統計 CSV」或「⬇️ 明細 CSV」。
- 檔案為 UTF-8（含 BOM），Excel 可直接開啟中文；會員 LINE 識別已遮罩；不含任何權杖或登入資訊。
- 這是營運用清單；完整備份與搬家請使用「系統設定 → 資料搬家」。

## E. 付款狀態（C5.4）

- 顧客端與後台的付款狀態一律以伺服器判定：等待付款、已付款、付款失敗（本次付款未完成）、付款結果確認中（請勿重複付款）、取餐時付款、已付款・待退款、已退款。
- 「付款結果確認中」的付款：不要請顧客重新付款或改現金。到後台「LINE Pay 付款待核對」按「向 LINE Pay 查詢核對（唯讀）」（快閃付款為「唯讀核對此筆」），並對照 LINE Pay 商家後台。
- 已付款・待退款：請在 LINE Pay 商家後台退款後，於訂單按「標記已退款」。系統不會自動退款。

## F. 真機驗收（最短步驟；未完成前請勿開啟自動通知）

1. 測試帳號加入官方帳號好友 → 在點餐頁對一個暫停販售的測試商品「補貨登記」並同意通知。
2. 手動預覽並確認發送 → 手機收到訊息、點連結開到該商品；成效頁出現 1 次點擊。
3. 把測試商品勾選參與自動通知、開啟全店自動通知（總開關需開啟）→ 再用另一個測試帳號登記 → 把商品恢復可販售 → 手機收到訊息；「自動通知紀錄」顯示已建立通知批次。
4. 再按一次「可販售」、或停售後再恢復 → 不會收到第二則（紀錄顯示「本週期已通知」）。
5. 關閉自動通知，確認之後恢復販售不再發送。
6. 匯出明細 CSV，以 Excel 開啟確認中文與欄位正確。
