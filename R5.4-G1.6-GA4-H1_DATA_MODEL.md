# R5.4-G1.6-GA4-H1 — Data Model

三張全新、獨立、additive 資料表，加入 `utils/db.js`（safe migration：只用
`CREATE TABLE IF NOT EXISTS` / `CREATE INDEX IF NOT EXISTS`，不 DROP／不
修改 `geo_visit_log`、`analytics_events` 或任何既有表）。

## ga4_geo_realtime_snapshots

GA4 Realtime 城市彙總快照，5 分鐘切桶。

| 欄位 | 型別 | 說明 |
|---|---|---|
| id | INTEGER PK | |
| store_id | TEXT NOT NULL | |
| property_id | TEXT NOT NULL | Property Binding 參照 |
| captured_bucket_utc | TEXT NOT NULL | 5 分鐘桶（Unique Key 之一） |
| captured_at_utc / captured_at_taipei | TEXT | |
| window_minutes | INTEGER DEFAULT 30 | |
| country_raw / region_raw / city_raw | TEXT | GA4 原始值，永久保留 |
| raw_location_key | TEXT NOT NULL | country+region+city 正規化字串 |
| country_code / county_code / county_name / district_code / district_name | TEXT | 正規化後的台灣行政區代碼 |
| normalization_status | TEXT DEFAULT 'unknown' | ok / ambiguous / unknown / overseas_or_other |
| administrative_level | TEXT | district / county / null |
| active_users_30m / event_count_30m | INTEGER DEFAULT 0 | |
| source / metrics_version / normalization_version / sync_run_id | TEXT | |
| created_at | TEXT | |

**Unique Key**：`(store_id, property_id, captured_bucket_utc,
raw_location_key, metrics_version)` — 同一桶重跑 upsert，不重複插入。

**Index**：`idx_ga4geo_rt_store_bucket`、`idx_ga4geo_rt_store_district`。

## ga4_geo_range_stats

完整日期區間（today/yesterday/7d/30d/custom）的 GA4 正式報表快取。

| 欄位 | 型別 | 說明 |
|---|---|---|
| range_start_date / range_end_date | TEXT NOT NULL | |
| timezone | TEXT DEFAULT 'Asia/Taipei' | |
| active_users / new_users / sessions | INTEGER | Audience Query |
| page_view_count / view_item_count / view_product_count / add_to_cart_count / begin_checkout_count / checkout_click_count / purchase_count | INTEGER | Funnel Query（server pivot） |
| transaction_count / purchase_revenue / currency | | Commerce Query（currency 目前恆為 NULL，見 Reality Audit） |
| metrics_version / event_mapping_version / normalization_version | TEXT | |
| synced_at_utc / sync_run_id / updated_at | TEXT | |

**Unique Key**：`(store_id, property_id, range_start_date, range_end_date,
raw_location_key, metrics_version, event_mapping_version)`。

**Index**：`idx_ga4geo_range_store_range`、`idx_ga4geo_range_store_district`。

## ga4_geo_sync_runs

每一次同步（realtime/range/backfill）的稽核記錄。

| 欄位 | 說明 |
|---|---|
| sync_type | realtime / range / backfill |
| status | running / success / partial / failed / blocked |
| rows_received / rows_saved / rows_unknown / rows_overseas / requests_used | |
| error_code / error_message_safe | 絕不含 credential／raw error |
| partial / stale_fallback_used | INTEGER (0/1) |

**Index**：`idx_ga4geo_syncruns_store_time`、`idx_ga4geo_syncruns_store_type`。

## 禁止事項（已由 Static Audit + Mutation Negative 驗證）

- 三張表完全不含 `visitor_id`、`user_pseudo_id`、`client_id` 欄位。
- 完全不寫入 `geo_visit_log`。
- 不保存 Service Account JSON / Access Token / Refresh Token / Raw GA4
  Response。
